Значки кнопок ленты «Зум-зум»

  Whole.png     — «Весь чертёж» (палитра с красками)
  Frame.png     — «Рамка» (кирпич с мастерком)
  Ref.png       — «Отрезок»
  Highlight.png — «Подсветить экраны» (планета в каске)
  Settings.png  — «Настройки» (скрещённые молот и кирка)

Остальные кнопки («Передвинуть с видовым», «Разделить по листам», «Собрать в один»)
рисует код — DwGangsta\RibbonIcons.cs. Положите сюда <имя>.png, и кнопка возьмёт
картинку; для «Передвинуть с видовым» имя — MoveViews.

Файлы вшиваются в ZoomZoom.dll при сборке. Чтобы поменять значок, поправьте
PNG и пересоберите плагин (deploy.ps1 или Ctrl+Shift+B). Размер любой
квадратный: 48×48, 64×64, 128×128 и т. д. AutoCAD сам приведёт его к 32 px
(крупная кнопка) и 16 px (мелкая). Фон — прозрачный.

Для мелких деталей рядом лежат заранее уменьшенные картинки:
<имя>_32.png (64×64) для крупной кнопки и <имя>_16.png (32×32) для мелкой —
лента берёт их вместо ужатой большой.

Если файла нет или он не читается, кнопка рисует значок кодом (RibbonIcons.cs).
Удалили картинку — пересоберите начисто (dotnet build -c Release --no-incremental):
обычная сборка удаления не замечает и оставляет в DLL старую картинку.
